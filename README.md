# Sorting Algorithm Visualizer

An interactive web project that visualizes sorting algorithms step by step.

## Features

- Bubble Sort, Selection Sort, and Insertion Sort
- Generate random numbers or enter custom numbers
- Sorting speed control
- Live comparison and swap counters
- Visual bar animations with reset option
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

This project helped me practice arrays, for loops and nested loops, functions, DOM manipulation, event listeners, classList, and traversing element children. It also introduced async/await, Promises, and setTimeout to control animation timing, along with the core logic of sorting algorithms.

## About The Project

Numbers are represented as visual bars. As each sorting algorithm runs, the bars are compared and moved step by step so the sorting process can actually be seen, not just the final result.

## Algorithms

**Bubble Sort** — Compares adjacent values and swaps them when they are in the wrong order.

**Selection Sort** — Finds the smallest value in the unsorted portion and places it in its correct position.

**Insertion Sort** — Takes values one by one and inserts each into its correct position among the already sorted values.
